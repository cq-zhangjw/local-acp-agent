# v3.7.1 发布说明

## 新增

- **日语注音开关**：composer 工具栏加"注音"按钮（LanguageOutline 图标），按会话存储。快捷指令表单也加了该开关，点卡片时联动。
- **新建会话重置工具栏**：新建会话时自动恢复默认（联网搜索开、历史开、注音开、角色预设清除）。
- **角色预设按会话存储**：切换会话时恢复该会话激活的角色。
- **侧边栏分组自动折叠**：新建聊天会话展开普通会话组，新建 Task 会话展开 Agent 会话组。

## 修复

- **markdown 渲染被注音破坏**：jp-mark 后端不再 escape 非日语文本，前端始终走 markdown-it 渲染（ruby 标签通过 html:true 保留）。
- **注音结果丢失**：autoJpMark 完成后立即 saveConversation，不再依赖下一次发消息。
- **中文被误判为日语注音**：MeCab span 扩展后检查假名密度，<15% 拒绝标注。
- **复制带读音**：ruby `<rt>` 设为 `user-select: none`，拖选/复制只拿汉字。
- **角色编辑器按钮位置**：改用 NModal footer slot，右下角对齐。
- **快捷指令表单顺序**：标题 → 模式 → 关联角色 → 预输入内容。

## 变更

- 快捷指令去掉 `type` 字段，新增 `role`（关联角色预设名）。
- 角色预设独立存储到 `.deepagents/roles/<名>.md`，左右布局编辑器。
- webSearchOn/historyOn/jpMarkOn 从全局 localStorage 改为按会话存储。

## 升级注意

- 后端新增 `/api/roles` 路由，需重启后端。
- 旧的 `.deepagents/quick_commands.json` 里 `type` 字段会被忽略，不影响使用。
