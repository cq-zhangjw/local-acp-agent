# v3.6 Release Notes

## 新功能

### 1. 联网搜索 MCP（web_search_server）
- 用 Playwright 无头 Chromium 爬 cn.bing.com / baidu.com，免费无 API key
- 工具 `search_web(query, engine="bing"|"baidu", max_results=8)`
- 已注册到 default agent

### 2. Chat 模式联网搜索开关
- Composer 工具栏新增 GlobeOutline "联网搜索" 按钮（仅 chat 模式显示）
- 开关状态存 localStorage，默认关
- 开启时 Chat agent 动态加载 `search_web` 工具，system prompt 注入"先搜再答、引用来源"指令
- WS query param `&web_search=1` → 后端 `WEB_SEARCH` env

### 3. 快捷指令（Quick Commands）
- 输入框下方卡片流，新会话欢迎页显示
- 第一张虚线"新建"卡片，点击卡片自动切换 agent/model/mode 并填入指令
- 后端用 MooFile BSON 存储（`db/db_quick_commands_<hash>/`）
- 用户消息 ... 菜单新增"添加至快捷指令"入口，自动填充内容
- 表单：模式优先，chat 模式锁模型+强制 agent=Chat，task 模式隐藏 Chat agent

## UI 优化

### 推理过程折叠
- AI 回复完成后，所有 thought/tool/plan 步骤（含中间过程旁白 text）收进一个折叠块
- 折叠头显示"🔧 N 步推理过程（点击展开）"，三语 i18n
- 最终回答只显示最后一个 text 块
- Running 时照旧实时流式显示
- 展开后内部 padding/spacing 调优，无嵌套缩进

### 其他 UI
- Agent 下拉图标文字间距 3px
- Task 模式隐藏 Chat agent 选项
- 子 agent 面板改为开关控制 subagents 字段
- 上下文统计加入 overhead（system prompt + 工具 schema）
- 流式输出时每 2 秒节流刷新上下文百分比
- ThoughtCard done 后折叠，历史刷新计时器不从 0 开始

- 多轮工具调用时新思考追加到旧 done 卡片
