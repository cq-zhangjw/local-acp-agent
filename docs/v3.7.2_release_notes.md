# v3.7.2 发布说明

## 修复

- **角色预设注入方式**：从拼在用户消息前改为真正的 system prompt（ws `?role=` → 后端读 md → `build_system_prompt`）。
- **上下文查看页显示真实 system prompt**：抽出 `build_system_prompt(agent, role, web_search)` 共享函数，agent 启动和 debug 页都调它，不再自己拼接。
- **system prompt 格式**：`# Global rules`（基础）+ `# User preset`（角色），用户预设优先。
- **新建会话不再强制重置开关**：保留用户在欢迎页的选择。
- **角色预设不被新建会话清除**：选了角色发消息会带入新会话。
- **注音结果持久化**：autoJpMark 完成后立即 saveConversation。
- **中文误判日语**：MeCab span 假名密度 <15% 拒绝标注。
- **复制带读音**：ruby `<rt>` 设为 `user-select: none`。
- **上下文查看页**：system prompt 和工具 schema 分开折叠，system prompt 不截断。

## 新增

- **日语注音开关**：composer 工具栏加"注音"按钮，按会话存储，快捷指令可关联。
- **快捷指令关联角色**：去掉 type 字段，加 role 选择。
- **侧边栏分组自动折叠**：新建聊天/Task 会话时自动展开对应组。

## 升级注意

- 需重启后端（新增 `/api/roles` 路由、`build_system_prompt` 重构）。
