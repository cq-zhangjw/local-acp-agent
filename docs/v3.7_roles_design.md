# v3.7 — 角色预设与快捷指令分离设计

## 背景

之前 `type=prompt` / `type=system` 两种快捷指令混在一起，逻辑混乱。现在拆成两个独立概念：

- **角色预设（Role Preset）**：一段 system prompt，决定 AI 的人设/行为规范。独立存储，独立切换。
- **快捷指令（Quick Command）**：一键填入输入框的常用 prompt，可选关联一个角色预设。

## 数据结构

### 角色预设：`.deepagents/roles/<name>.md`

每个角色一个 md 文件，文件名即 slug，文件内容就是 system prompt 正文。
frontmatter 可选（title），目前直接用文件名做标题。

列表：扫描 `.deepagents/roles/*.md`，读文件名 + 内容前 N 字做预览。

### 快捷指令：`.deepagents/quick_commands.json`

去掉 `type` 字段，新增 `role` 字段（角色名，空字符串=不关联）。

```json
{
  "id": "qc_xxx",
  "title": "...",
  "content": "...",
  "agent": "Chat",
  "model": "",
  "mode": "chat",
  "autoSend": false,
  "webSearchOn": true,
  "historyOn": true,
  "role": "中日英翻译助手",
  "createdAt": "..."
}
```

## API

### Roles

- `GET /api/roles` → `{ok, items: [{name, content, preview}]}`
- `PUT /api/roles/:name` → 新建/覆盖（body: `{content}`）
- `DELETE /api/roles/:name`

### Quick Commands

- `GET /api/quick-commands` → 不变
- `POST /api/quick-commands` → body 去掉 type，加 role
- `PUT /api/quick-commands/:id` → 同上

## 前端

### 角色预设弹框（composer 常驻按钮）

- 顶部搜索框
- 卡片网格：第一张虚线"新建角色"
- 新建/编辑弹框：左右布局
  - 左：textarea 纯文本编辑
  - 右：markdown 实时预览
- 保存：写入 `.deepagents/roles/<title>.md`
- 点卡片：激活该角色（composer pill 显示角色名），推理时把文件内容作为 system override 注入

### 快捷指令（欢迎页卡片）

- 表单去掉"类型"select
- 加"关联角色"select（选项来自 roles API，默认"不关联"）
- 点卡片：填入 content + 应用关联角色（如果有）+ 应用 chat toggles

## 后端注入

acp_agent.py Chat 分支：收到 system override（角色 md 内容）时，拼到 messages 前面。
前端 ws 连接时传 `role=<name>`，后端读对应 md 文件内容作为 system prompt。
